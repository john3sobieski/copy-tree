# CopyTree

Инструмент для контекстного меню Проводника Windows: копирует в буфер обмена дерево папки или полный путь к файлу. Удобно, чтобы показать ИИ структуру проекта.

- **Папка** (или пустое место внутри папки): копируется дерево папки в стиле `tree`.
- **Файл**: копируется его абсолютный путь одной строкой, например `C:\proj\src\main.rs`.

```
proj/
├── src/
│   ├── main.rs
│   └── tree.rs
├── Cargo.toml
└── README.md
```

Папки, пропущенные из-за игнор-списка или `.gitignore`, всё равно показываются с пометкой `node_modules/ [skipped]`: видно, что они есть, но без содержимого.

Пункты меню: «Скопировать дерево папки» и «Скопировать путь к файлу». Меню и все окна следуют языку интерфейса Windows (встроены английский и русский, запасной язык: английский).

## Установка

1. Скачайте `copytree.exe` со страницы Releases.
2. Запустите двойным кликом. Exe копирует себя в `%LOCALAPPDATA%\CopyTree\` и добавляет пункты меню. Права администратора не нужны.
3. Скачанный exe можно переместить или удалить, меню продолжит работать.

Рассчитано на Windows 10. В Windows 11 пункты должны появиться в разделе «Показать дополнительные параметры» (не проверялось).

## Обновление и удаление

Параметров командной строки нет. Запустите двойным кликом exe, когда CopyTree уже установлен:

- **Да** на вопрос «Обновить его этим exe?» заменяет установленный exe. Настройки сохраняются.
- **Нет**, затем **Да** на вопрос «Удалить CopyTree из меню Проводника?» удаляет пункты меню и папку установки.

## Настройки

Файл: `%LOCALAPPDATA%\CopyTree\copytree.toml`, создаётся при первом использовании, все настройки в нём закомментированы. Чтобы переопределить настройку, уберите в начале строки `# `. Изменения применяются при следующем клике. Удалите файл, чтобы вернуть значения по умолчанию.

| Настройка | По умолчанию | Значение |
|---|---|---|
| `max_depth` | `100` | Максимальная глубина папок (выбранная папка это уровень 0). |
| `max_entries` | `1000000` | Максимальное число строк; остальное обрезается с пометкой `... (truncated at N entries)`. |
| `use_gitignore` | `true` | Учитывать также файлы `.gitignore` внутри выбранной папки. |
| `show_sizes` | `true` | Показывать размер файла после имени, например `main.rs (1.2 KB)`. У папок размера нет. |
| `ignore` | см. ниже | Имена или маски (например `*.pyc`), пропускаемые на любой глубине. Пропущенные папки показываются как `name/ [skipped]`, пропущенные файлы скрыты. Свой список заменяет список по умолчанию. |

Игнор-список по умолчанию:

- Контроль версий: `.git`, `.svn`, `.hg`
- Зависимости и результаты сборки: `node_modules`, `target`, `dist`, `build`, `out`, `__pycache__`, `*.pyc`, `.venv`, `venv`, `.next`, `.nuxt`, `.gradle`
- Редакторы и IDE: `.vs`, `.idea`, `.vscode`
- Кэши: `.cache`, `.pytest_cache`, `.mypy_cache`
- Системные файлы: `.DS_Store`, `Thumbs.db`, `desktop.ini`

Примечания:

- Сама выбранная папка никогда не игнорируется (нажмите ПКМ на `node_modules`, чтобы увидеть её содержимое).
- Папки, исключённые через `.gitignore`, тоже помечаются `[skipped]`.
- Сначала идут папки, затем файлы, и те и другие по имени. Скрытые файлы показываются. Символические ссылки перечисляются, но не раскрываются.
- Если выбрать несколько файлов, Проводник запустит CopyTree по одному разу на каждый файл, и в буфере останется только последний путь.

## Переводы

Пункты меню и окна это строковые ресурсы внутри exe (`assets/strings.rc`); Windows выбирает язык, совпадающий с языком интерфейса пользователя. Текст меню хранится в реестре как косвенная строка (`@exe,-ID`), поэтому он тоже следует смене языка без переустановки. Само дерево (`[skipped]`, `... (truncated ...)`) всегда на английском.

Чтобы добавить язык, скопируйте блок в `assets/strings.rc`, измените строку `LANGUAGE` и переведите тексты. ID должны остаться прежними и совпадать с `src/strings.rs`.

Переводы этого README лежат в папке [`i18n`](.).

## Сборка

Нужен Rust 1.79+ на Windows.

```
cargo build --release
```

Exe будет в `target\release\copytree.exe`. GitHub Actions тоже собирает его при каждом пуше и выкладывает как артефакт.
